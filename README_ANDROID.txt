漫画制作カレンダー 自分専用 Android版 v13
==========================================

今回の修正
----------
1. 日別詳細のスクロールを翌2:00まで確実に表示
   ・スマホの詳細画面は、内側の画面だけを縦スクロールするよう整理。
   ・Android向け慣性スクロールを有効化。
   ・タイムライン下側に余白を追加し、翌02:00を画面内まで持ち上げられるようにしました。
   ・タイムラインの最下部に「翌02:00」ラベルも表示します。

2. 時刻入力をAndroid標準のアナログ時計UIから変更
   PC / Androidとも同じデジタル入力方式にしました。

   例:
   開始 [ 21 ] : [ 00 ]
   終了 [ 23 ] : [ 00 ]

   時の選択肢:
   07〜23
   翌00
   翌01
   翌02

   分は0〜59を数字で直接入力できます。

3. 深夜の表示を分かりやすく変更
   00:30 は「翌00:30」
   01:15 は「翌01:15」
   02:00 は「翌02:00」
   と表示します。

4. 既存データ
   v12のデータはv13へ自動で引き継ぎます。
   これまで保存した23時以降〜翌2時の予定もそのまま編集できます。
