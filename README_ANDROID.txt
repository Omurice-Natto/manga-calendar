漫画制作カレンダー 自分専用 Android版 v13
==========================================

今回の修正
----------
・スマートフォンの日別詳細タイムラインを午前2時まで確実にスクロールできるよう調整。
・深夜0時以降を翌日表記ではなく、制作日の続きとして表示。

表示例:
22:00
23:00
24:00
25:00
26:00

対応関係:
24:00 = 翌日 00:00
25:00 = 翌日 01:00
26:00 = 翌日 02:00

入力について
------------
Android / Chromeの時刻入力欄は24:00〜26:00を直接入力できないため、
予定追加・編集画面では従来どおり、

00:00 = 24:00
01:00 = 25:00
02:00 = 26:00

として入力します。

保存後の予定一覧とタイムライン上では24〜26時表記になります。

スクロール
----------
・日別詳細ダイアログの縦スクロールを明示的に有効化。
・スマホの慣性スクロールに対応。
・26:00のラベルが画面下端で切れないよう、タイムライン下部に余白を追加。
・Androidのナビゲーションバー付近でも26:00まで到達しやすい余白を追加。

データ
------
v12のデータはv13へ自動で引き継ぎます。
