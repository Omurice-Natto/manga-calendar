漫画制作カレンダー 自分専用 Android版 v12
==========================================

今回の変更
----------
1. 詳細時間予定のデフォルト時間
   新しい予定を追加すると、
   開始 21:00
   終了 23:00
   が最初から入るようにしました。

2. 詳細時間予定の色を選択可能
   4色から選べます。

   ・紺    デフォルト
   ・緑
   ・橙
   ・紫

   予定ごとに色を変えられるので、
   例：
   紺 = 漫画作業
   緑 = 勉強
   橙 = 外出
   紫 = その他
   のような使い分けができます。

3. 色はタイムラインと予定一覧の両方に反映
   タイムラインの時間帯ハイライトと、
   上部の予定一覧の左端に同じ色が表示されます。

データ
------
v11の自分専用版データはv12へ自動で引き継ぎます。
既存の詳細時間予定はデフォルトの紺色になります。

PWA
---
キャッシュ名をv12へ更新しています。
GitHub Pagesへ上書きした場合、新しいCSS/JSへ更新されます。
