漫画制作カレンダー v10 - 自分専用 Android / PC版
=================================================

この版の方針
------------
・自分1人で使う前提です。
・ログイン / ユーザー登録 / DBはありません。
・入力したデータは、その端末・そのブラウザの localStorage に保存します。
・PCでは従来の横長カレンダー表示。
・Androidなど画面幅700px以下では、1日ごとの縦カード表示へ自動切替します。
・PWA対応。Android Chromeからホーム画面へ追加できます。
・一度読み込めば、基本画面はオフラインでも起動できます。

Android版の主な調整
-------------------
・横スクロール前提を廃止し、1日1カードの縦表示。
・制作予定は日付の下へ縦並び。
・長期予定は上部で横スクロール可能。
・日別詳細は画面いっぱいに表示。
・入力ダイアログ、ボタン、プルダウンをタッチしやすいサイズへ調整。
・端末のノッチ / ジェスチャーバー用 safe-area に対応。

インストールについて
--------------------
PWAとしてAndroidのホーム画面に入れるには、HTTPSで公開する必要があります。
index.htmlをスマホの「ファイル」から直接開いただけでは、PWAインストールと
Service Workerによるオフライン機能は利用できません。

GitHub Pagesなどにこのフォルダ一式を置き、Android ChromeでURLを開いてください。
条件が揃うと上部に「アプリ化」ボタンが表示されます。
表示されない場合はChromeのメニューから「ホーム画面に追加」または
「アプリをインストール」を選択してください。

重要: データの保存場所
----------------------
このアプリをGitHub Pages等に置いても、あなたが入力した予定データは
GitHubへ送信されません。保存先はAndroid/PC内のブラウザストレージです。

そのためAndroidとPCのデータは自動同期しません。
バックアップ / 復元ボタンでJSONを移動できます。

機種変更・ブラウザデータ削除の前には、必ず「バックアップ」を行ってください。

v9からのデータ
---------------
同じURL・同じブラウザ上でv9からv10へ更新した場合、v9のlocalStorageデータを
自動的にv10へ引き継ぎます。
